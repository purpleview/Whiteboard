# Whiteboard REST API

The whiteboard server can be controlled through a small REST API. This document replaces the
apidoc pages that used to be generated at startup under `[rootUrl]/apidoc/index.html`. It
describes the behaviour of `scripts/server-backend.js`; where the old apidoc annotations in that
file differ from the code, this document follows the code.

`[rootUrl]` is the URL the whiteboard is served from, e.g. `http://localhost:8080`.

## Common parameters

| Parameter | Type   | Description                                                                                                                                                                    |
| --------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `wid`     | String | Whiteboard ID, as found in the whiteboard URL (`whiteboardid=...`). Any string; the frontend generates UUIDs.                                                                  |
| `at`      | String | Access token. Only required if `backend.accessToken` is set in the server configuration (see `config.default.yml`). With an empty token (default) every request is authorized. |

Every whiteboard has a corresponding **read-only whiteboard ID**, a UUID generated by the server
on first use (see [getReadOnlyWid](#get-apigetreadonlywid)). Viewers with that ID can watch but not draw.

## GET /api/health

Health check. Returns an empty body.

| Status | Meaning      |
| ------ | ------------ |
| 200    | Server is up |

```
curl -i [rootUrl]/api/health
```

## GET /api/loadwhiteboard

Returns everything that was ever drawn on the whiteboard as a JSON array of draw events (see
[drawToWhiteboard](#get-apidrawtowhiteboard) for their format). The frontend calls this when a
whiteboard is opened.

| Parameter | Required      | Description                              |
| --------- | ------------- | ---------------------------------------- |
| `wid`     | yes           | Whiteboard ID or read-only whiteboard ID |
| `at`      | if configured | Access token                             |

| Status | Body                                                                                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 200    | JSON array, e.g. `[{"t":"rect","c":"red","th":"4","d":["10","10","100","80"],"username":"api"}]`; `[]` for an unknown whiteboard |
| 401    | Wrong access token                                                                                                               |

The server keeps whiteboards in memory and removes them 12 hours after it first loaded them. With
`backend.enableFileDatabase` they are also saved to files and reloaded from there on the next
request; otherwise the content is gone.

```
curl -i "[rootUrl]/api/loadwhiteboard?wid=MyWhiteboardId"
```

## GET /api/getReadOnlyWid

Returns the read-only whiteboard ID for a whiteboard ID as plain text. The ID is created on first
request and stays the same for the lifetime of the server process.

| Parameter | Required      | Description   |
| --------- | ------------- | ------------- |
| `wid`     | yes           | Whiteboard ID |
| `at`      | if configured | Access token  |

| Status | Body                                                                 |
| ------ | -------------------------------------------------------------------- |
| 200    | Read-only whiteboard ID, e.g. `7a3fb403-645e-4e66-a565-c3bab46d19cf` |
| 401    | Wrong access token                                                   |

```
curl -i "[rootUrl]/api/getReadOnlyWid?wid=MyWhiteboardId"
```

## POST /api/upload

Uploads an image to the server. The image is **not** added to the whiteboard automatically: call
[drawToWhiteboard](#get-apidrawtowhiteboard) with `t=addImgBG` and the resulting URL afterwards.

The request body is a form (`application/x-www-form-urlencoded` or `multipart/form-data`) with
these fields:

| Field          | Required      | Description                                                                                                                                                                                                                                     |
| -------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wid`          | yes           | Whiteboard ID (not the read-only ID)                                                                                                                                                                                                            |
| `imagedata`    | yes           | Base64 encoded image, optionally prefixed with `data:image/png;base64,` or `data:image/jpeg;base64,`                                                                                                                                            |
| `at`           | if configured | Access token                                                                                                                                                                                                                                    |
| `date`         | no            | Timestamp used in the file name. Defaults to the current time in milliseconds. Only set it if you need to know the file name in advance.                                                                                                        |
| `webdavaccess` | no            | Also store the image on a WebDAV server. JSON-encoded object `{"webdavserver": "https://host/remote.php/webdav/", "webdavpath": "/folder/", "webdavusername": "...", "webdavpassword": "..."}`. Only works if `backend.enableWebdav` is `true`. |

The image is stored as PNG at:

```
[rootUrl]/uploads/[readOnlyWid]/[readOnlyWid]_[date].png
```

| Status | Body / meaning                                                                       |
| ------ | ------------------------------------------------------------------------------------ |
| 200    | `done`                                                                               |
| 401    | Wrong access token, or `wid` is a read-only whiteboard ID                            |
| 403    | Connection to the WebDAV server failed                                               |
| 500    | Missing `imagedata`, WebDAV disabled on the server, or the file could not be written |

```
curl -i -X POST --data-urlencode "imagedata=data:image/png;base64,iVBORw0KGgo..." \
     -d "wid=MyWhiteboardId&date=1700000000000" [rootUrl]/api/upload
```

## GET /api/drawToWhiteboard

Draws on the whiteboard. The event is sent to all clients of the whiteboard and of its read-only
whiteboard and stored on the server (it is part of the [loadwhiteboard](#get-apiloadwhiteboard)
result afterwards).

| Parameter  | Required       | Description                                                                                                                    |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `wid`      | yes            | Whiteboard ID (read-only IDs are rejected with 401)                                                                            |
| `at`       | if configured  | Access token                                                                                                                   |
| `t`        | yes            | Tool, see table below                                                                                                          |
| `d`        | depends on `t` | Data array, passed as `d[]=...&d[]=...` (or `d[0]=...&d[1]=...`). Coordinates are in pixels relative to the whiteboard origin. |
| `c`        | no             | Color, used by tools that draw with a color (`pen`, `line`, `rect`, `circle`)                                                  |
| `th`       | no             | Line thickness in pixels (`pen`, `line`, `rect`, `circle`, `eraser`)                                                           |
| `username` | no             | Name of the user performing the action. Only relevant for `undo` and `redo`, which revert the actions of this user.            |
| `draw`     | no             | Only for `t=addImgBG`: `1` draws the image into the canvas, otherwise it is placed in the background                           |
| `url`      | for `addImgBG` | Image URL, normally `[rootUrl]/uploads/[readOnlyWid]/[readOnlyWid]_[date].png` from [upload](#post-apiupload)                  |

Tools and the meaning of `d`:

| `t`                         | `d`                                                                                                                                             |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `pen`, `line`               | `[x1, y1, x2, y2, x3, y3]` - three consecutive points of a smoothed stroke; the legacy form `[fromX, fromY, toX, toY]` draws a straight segment |
| `rect`                      | `[fromX, fromY, toX, toY]`                                                                                                                      |
| `circle`                    | `[centerX, centerY, radius]`                                                                                                                    |
| `eraser`                    | `[fromX, fromY, toX, toY]` (uses `th`)                                                                                                          |
| `eraseRec`                  | `[left, top, width, height]`                                                                                                                    |
| `recSelect`                 | `[fromX, fromY, toX, toY, width, height]` - moves the selected area                                                                             |
| `addImgBG`                  | `[width, height, left, top, rotationAngle]` (uses `url` and `draw`)                                                                             |
| `addTextBox`                | `[textColor, backgroundColor, fontSize, left, top, textboxId, isStickyNote]`                                                                    |
| `setTextboxText`            | `[textboxId, text]` - `text` is Base64 encoded UTF-8 HTML                                                                                       |
| `removeTextbox`             | `[textboxId]`                                                                                                                                   |
| `setTextboxPosition`        | `[textboxId, top, left]`                                                                                                                        |
| `setTextboxFontSize`        | `[textboxId, fontSize]`                                                                                                                         |
| `setTextboxFontColor`       | `[textboxId, color]`                                                                                                                            |
| `setTextboxBackgroundColor` | `[textboxId, color]`                                                                                                                            |
| `clear`                     | none - clears the whiteboard                                                                                                                    |
| `undo`, `redo`              | none - uses `username`                                                                                                                          |

All values arrive as strings (e.g. `"10"`), the frontend converts them as needed.

| Status | Body / meaning                                    |
| ------ | ------------------------------------------------- |
| 200    | `done`                                            |
| 400    | `t=setTextboxText` without a text in `d[1]`       |
| 401    | Missing or read-only `wid`, or wrong access token |

```
curl -i "[rootUrl]/api/drawToWhiteboard?wid=MyWhiteboardId&t=rect&c=red&th=4&d[]=10&d[]=10&d[]=100&d[]=80"
```

## Not covered here

The browser clients talk to the server via Socket.IO on the path `/ws-api` (events such as
`joinWhiteboard`, `drawToWhiteboard`, `toggleToolbar`). This channel is internal to the frontend
and not documented as a public API.
